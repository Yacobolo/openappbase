# Context Documentation

Up-to-date reference docs for project technologies.

## Contents

### Core Technologies

Each has `llms.md` (full docs) + `toc.md` (line-numbered index):

- **`datastar/`** - SSE framework, reactive bindings (`data-on:*`, `data-bind`), server-side Go SDK
- **`daisyui/`** - Component library, Tailwind integration, semantic tokens, theming
- **`nats/`** - Pub/sub messaging, request/reply, fanout patterns
- **`templ/`** - Go HTML templates, component syntax, live reload
- **`opencode/`** - OpenCode agent documentation

### Go Package APIs

- **`go-packages/datastar-go/`** - SSE helpers, signal reading, compression
- **`go-packages/chi/`** - Router, middleware, context
- **`go-packages/pgx/`** - PostgreSQL driver, pooling, query execution
- **`go-packages/nats-go/`** - Pub/sub, JetStream, key-value
- **`go-packages/gorilla-sessions/`** - Session store interface
